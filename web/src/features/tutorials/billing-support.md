# 计费与支付

充值时请核对三个金额：写入账户余额的充值金额、单独收取的服务费，以及两者相加的实付金额。服务费用于服务器、网络带宽和日常运维。

| 单笔充值金额（人民币） | 服务费率 | 实付示例 |
| --- | --- | --- |
| 50 元至 100 元，含两端 | 9% | 充值 100 元，实付 109 元 |
| 超过 100 元且低于 1,000 元 | 8% | 充值 500 元，实付 540 元 |
| 1,000 元及以上 | 7% | 充值 1,000 元，实付 1,070 元 |

最后一个例子中，可用于模型调用的余额是 1,000 元。模型单价可在[模型广场](/pricing)查看，每次调用的扣费可在[使用日志](/usage-logs)核对。

## 订单异常与退款申请

如果已付款但余额未到账，请先核对支付记录，避免重复付款。遇到重复支付、金额有误，或者希望就未使用余额申请退款，可以写信至 [support@holliday.win](mailto:support@holliday.win)。

请提供站内用户名、订单号、付款时间、实付金额以及希望核查的问题。涉及 API 扣费时，可附上请求编号。本站会核对支付结果、到账额度和已用余额，并通过邮件告知处理结果；如涉及退款，会说明金额和退款方式。
