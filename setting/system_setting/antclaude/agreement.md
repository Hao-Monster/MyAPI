## 服务与账户

Ant-Claude 提供独立的模型调用和计费服务。站内余额用于本站 API 调用。可用模型、调用方式和单价见[模型广场](/pricing)。

请仅提交你有权处理的内容，遵守适用法律和所用模型的使用规则。请为每台设备创建独立密钥并设置额度。怀疑密钥泄露时，先在 [API 密钥](/keys)中禁用它，再核对近期用量。

## 充值与扣费

充值前请核对到账额度、服务费和实付金额。调用完成后，可在[使用日志](/usage-logs)核对模型、时间和扣费。如果出现扣款未到账、重复支付或用量争议，请按[计费与支付](/billing-support)中的方式提交核查。

## 服务中断与争议

模型供应商、网络或维护可能影响调用。若客户端超时，请先核对使用记录，再决定是否重试，以免产生第二次调用。发现异常访问或影响其他用户的请求时，本站可限制相应密钥；对处理结果有异议，可联系支持复核。

支持邮箱为 [support@holliday.win](mailto:support@holliday.win)。处理个人信息的方式及相关请求渠道见[隐私政策](/privacy-policy)。本条款不影响用户依法享有的权利。
