## 你提交给模型的内容

为了生成回复，网关会把请求中的提示词、你随请求提供的历史消息和附件内容，经 OpenRouter 发送给实际处理请求的模型供应商，再将结果返回客户端。请只提交你有权交给这些服务处理的信息。上游如何处理内容取决于所用模型、端点和供应商政策，详见 [OpenRouter 数据处理说明](https://openrouter.ai/docs/guides/privacy/data-collection)。

## 账户、订单和用量记录

本站使用账户标识和登录状态来验证身份，保存余额、充值订单及扣费记录以便对账。使用日志可记录请求时间、模型、令牌名称、Token 数量、扣费和请求编号。你可以在[使用日志](/usage-logs)查看自己的记录。本站不出售用户数据。

## 联系支持与隐私请求

发往支持邮箱的邮件经 Cloudflare 转交给本站客服邮箱。邮件地址、正文和附件用于处理你的请求。申请查询、更正或删除账户相关信息时，请从账户绑定邮箱写信至 [support@holliday.win](mailto:support@holliday.win)，说明请求范围。我们会核实身份，并说明处理结果以及因对账或法定义务需要保留的记录。

核查订单通常只需订单号、时间和金额。请勿发送账户密码、完整 API 密钥、银行卡号或与问题无关的对话内容。
