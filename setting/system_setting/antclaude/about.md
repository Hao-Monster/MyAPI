# 关于 Ant-Claude

Ant-Claude 是一个独立运营的模型 API 服务站。建站的起点，是站长的一次订阅经历：购买 Claude 年度订阅后，账户被停用，约 1,400 元订阅款未能退回。你可以在[首页的建站故事](/#ant-story-title)看到当时的收据和停用通知。

## 在这里可以做什么

你可以用自己的站内 API 密钥从客户端调用模型，在控制台核对用量和余额。可用模型和单价列在[模型广场](/pricing)。第一次使用 Windows 版 Claude Desktop，可以跟着[使用教程](/tutorials/claude-desktop-windows)完成配置。

## 费用与支持

本站按模型用量计费，充值服务费另列，用于服务器、带宽和日常运维。[计费与支付](/billing-support)说明了充值金额、服务费和异常订单的核对方式。

账户、订单或模型接入遇到问题，可以写信至 [support@holliday.win](mailto:support@holliday.win)。
